# 前端 UI 规范

现有文生图页面是控件外观的参考，新页面优先复用已有组件，不自行设计同类控件。

- 少量互斥选项（推理强度、清晰度等）统一使用 `src/components/SegmentedControl.vue`。通过 `modelValue`、`options` 和 `label` 接入；不另写单选按钮外观。
- 颜色使用 `src/styles/global.css` 中的语义变量。普通文字用 `--color-text`，辅助文字用 `--color-muted`，警告色仅用于实际警告状态。不可按色值范围自动判断用途。
- 分段选择外观沿用文生图清晰度：8 像素容器圆角、12 像素文字、灰白选中态。统一调整时修改共用组件，不分别覆盖各页面。
- 弹层、标签、按钮使用现有主题变量覆盖组件库默认样式，并核对实际文字与底色的对比。
- 页面背景放在内容下方。点阵主题下需要展示背景的页面根容器应透明，不能用不透明底色挡住点阵。
- 有参数选择的界面需核对组件状态、前端请求、后端字段和模型调用四个环节。未接通的选项必须说明尚未生效。
- 验收需在浏览器实际检查默认、悬停、选中、禁用及弹层状态；切换三种主题，核对背景可见和按钮可点击。类型检查和构建不能替代画面检查。

后续开发任务可直接附加：

> 请遵循《UI规范.md》，以现有文生图为视觉参考。先查找并复用现有组件；推理强度、清晰度等互斥选择必须使用 SegmentedControl。只用现有语义颜色，不新建同类控件样式。完成后实际检查三种主题及控件的选中和禁用状态。
