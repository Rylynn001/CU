# 制作板：固定创作台与自由创作画布

更新日期：2026-07-13

## 当前结论

制作板不再把每次生成结果渲染成 DAG，也不规定用户必须依次完成固定步骤。画布上的卡片是用户自行保留的创作上下文；固定底部创作台负责持续生成，完整结果保存在当前卡片的历史中。

产品差异是：创作面板保持固定，卡片可自由选择、摆放和继续分支。画布表达实际发生过的思考来源，但不把顺序或流程强加给用户。

## 已采用的交互

### 自由创作卡片

- 一张卡片代表一个可继续工作的创作上下文，例如角色轮廓、服装方向、主视觉或镜头运动。
- 卡片没有固定编号和全局顺序，可自由拖动和从任意卡片继续创作。
- “采用并新建”创建一张新卡片，并可选记录其来源卡片；从素材库加入画布的卡片保持独立。
- 卡片只显示当前采用媒体和历史数量，不显示图片标题、代数、父级谱系或批次栈。
- 只有实际存在来源的卡片才显示轻量贝塞尔曲线；曲线只提示创作来源，不参与业务关系计算。

### 画布内核

- 使用 `@vue-flow/core` 管理世界坐标、平移缩放、适应视口、卡片拖动和触控事件。
- 禁用自由连线、端口操作和节点删除；空白处左键拖拽直接框选，按住 Shift 可追加框选或点击复选，中键、右键或空格拖动用于平移画布。
- 创作卡片与 Group 是业务数据源；Vue Flow 节点与边只是视图投影。
- 固定创作台、生成决策和创作历史位于画布内核之外，不随视口移动。
- 来源曲线使用二次贝塞尔：`P0`、`P2` 是中心连线与两张卡片边界的交点，`P1` 的纵向偏移由目标与来源的高度差连续驱动；同高时接近平直，目标在上方或下方时曲线随之向上或向下过渡。超过长度阈值后从曲线中心对称渐隐。

### 固定创作台

- 每张卡片独立保存提示词、参考素材、模型、生成数量和高级参数。
- 切换卡片时，固定面板恢复该卡片自己的完整上下文。
- 新建关联创作时继承完整上下文，并将采用结果加入参考素材首位。

### 子面板 Group

- 多选至少两张根画布卡片后可打包为一个 Group；内部卡片保留批次、草稿、相对位置和来源关系。
- Group 主节点显示默认输出、内容数量和最多三个输出缩略图；双击进入独立子画布，面包屑或 Esc 返回。
- 根画布和每个子画布分别保存视口；第一版只允许一层 Group。
- 打包时所有选中卡片默认成为命名输出；子画布内可增减输出，Group 输出绑定卡片的当前采用版本。
- 选中 Group 时固定面板切换为输出管理，支持重命名、排序、设置默认输出、从输出新建和解散。
- 不提供手动拉线；从 Group 输出新建或添加参考时自动记录具体输出来源。

### 生成决策与历史

- 生成 1/2/4 个结果时不立即修改画布，而是打开中央决策窗口。
- `采用` 更新当前卡片，不增加画布卡片。
- `采用并新建` 保留当前卡片并创建一张可自由移动的新卡片。
- 关闭决策窗口不会丢弃结果，整批候选进入当前卡片历史。
- 历史按生成批次倒序展示；任意结果可以恢复为当前版本，或拆出为新的创作卡片。

## 数据边界

```ts
interface CreationCard {
  kind: 'creation'
  id: number
  source?: SourceRef
  title: string
  x: number
  y: number
  activeVersionId: string
  batches: GenerationBatch[]
  draft: CreationDraft
}

type SourceRef =
  | { kind: 'card'; cardId: number }
  | { kind: 'group-output'; groupId: number; outputId: string }

interface GroupOutput {
  id: string
  name: string
  cardId: number
}

interface GroupCard {
  kind: 'group'
  id: number
  title: string
  x: number
  y: number
  children: CreationCard[]
  outputs: GroupOutput[]
  defaultOutputId?: string
}

interface GenerationBatch {
  id: string
  versions: MediaVersion[]
  adoptedVersionId?: string
}
```

完整谱系不是画布结构。可选来源由 `SourceRef` 记录，Group 输出通过稳定 `outputId` 被引用；生成细节保存在批次、版本和参考素材中。未来接入后端时应持久化这些业务数据，而不是持久化 SVG 曲线。

## 规模目标

一个包含数百个生成结果的角色概念与视频项目，可以只保留用户认为值得继续的少量画布卡片，其余结果留在卡片历史中。连续生成不会强制创建卡片，也不会要求用户遵循预设流程。

## 暂不实现

- 完整谱系图与关系编辑模式
- Group 嵌套、谱系岛、阶段泳道和自动布局
- 自动命名
- 多人协作和后端持久化
- 偏好学习与潜空间插值
