# 对话技能目录

每个技能放在独立子目录，至少包含一个 `SKILL.md`：

```text
skills/
  my-skill/
    SKILL.md
```

说明文件示例：

```markdown
---
name: 我的提示词技能
description: >
  用于润色图片生成描述，保留人物、场景与素材引用。
---

用中文编写提示词，保留用户指定的主体、动作和引用编号。
```

目录名是稳定标识，`name` 是按钮中展示的名称，`description` 是说明，正文是模型使用的技能规则。支持多行说明；无法解析或正文为空的技能会跳过并记录日志。

新增、修改、删除后，在若晴AI输入框的“技能”菜单中点击“刷新技能列表”。选择后的规则用于后续发送的消息；选择“不指定技能”可取消。无需录入数据库，也不需要重启后端。

当前接入方式是读取技能说明指导模型回答、编写生成提示词；不会自动运行目录中的脚本。实际生成仍需在确认框中检查提示词和参数后提交。

需要把参考文档一并交给模型时，在 `SKILL.md` 头部声明：

```yaml
metadata:
  instruction_files:
    - references/style-library.md
```

选中技能后，后端将上述文件的完整正文追加到技能指令中。路径相对于该技能目录，不能引用目录之外的文件；缺少文件时停止调用并返回错误，不会在缺少参考资料的情况下继续。

图片提示词技能 `gpt-image-2-style-library` 已包含官方样式参考库。刷新列表并选中后，可发送“帮我优化一份中文饮料海报提示词，只要提示词，不生成图片”。接口调用使用 `skill_id: "gpt-image-2-style-library"`。

图片反推技能 `image-prompt-reverse` 包含上游技能正文及三份分析参考文档，不包含执行脚本。组件中选中后，后端根据 `optimization_node_id` 的入边读取上游图片；无需先填写提示词。对话窗口中选中后，通过 `@图片N` 引用画布图片，也可以通过附件选择图片。仅返回提示词，不执行生成。

组件提示词优化必须选择技能；取消选择后禁止优化，后端也会拒绝缺少 `skill_id` 的优化请求。多轮优化保留当前技能，每轮显式提交，不使用通用优化回退。
