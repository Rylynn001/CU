# 赛博朋克信使完整创作流程测试

## 目标

制作 **16:9 赛博朋克信使首帧图 + 30 秒视频**

## 系统能力确认

✅ **图片生成**: 已支持
- `list_image_models` - 查询可用图片模型
- `txt2img` - 文生图

✅ **视频生成**: 已支持  
- `list_video_models` - 查询可用视频模型
- `txt2video` - 文生视频

✅ **Seedance 提示词**: 已集成
- `generate_seedance_prompt` - 生成专业视频提示词

## 完整工作流

### 阶段 1: 生成 Seedance 视频提示词

**用户输入**:
```
制作 16:9 赛博朋克信使首帧图和 30 秒视频,主角是穿发光外套的女黑客
```

**系统响应**:
1. 检测到关键词 → 强制调用 `discover_tools`
2. 发现 `generate_seedance_prompt` 工具
3. 调用工具生成提示词
4. 返回完整的视频提示词(包含时间戳分镜、运镜、美学约束)

**期望输出**:
```
已为你生成 30 秒赛博朋克信使视频的专业提示词:

[完整 Seedance 提示词内容]

接下来你想:
1. 生成首帧图(推荐先生成,作为视频参考)
2. 直接生成视频
3. 只要提示词,自己去即梦平台操作

请告诉我你的选择,我会帮你调用对应的生成工具。
```

### 阶段 2A: 生成首帧图

**用户回复**: 
```
先生成首帧图
```

**系统响应**:
1. 调用 `list_image_models` 查询可用模型
2. 展示模型列表让用户选择
3. 用户选择模型后,调用 `txt2img`
4. 提交任务并返回 task_id

**期望输出**:
```

1. Flux Pro (id: 1) - 高质量写实风格
2. Stable Diffusion XL (id: 2) - 通用模型
3. Gemini Imagen (id: 3) - Google 图片生成

请选择模型编号(或直接说模型名称)
```

**用户选择**: `1` 或 "用 Flux Pro"

**系统执行**:
```

模型: Flux Pro
尺寸: 16:9
提示词: [首帧图提示词]

历史 ID: xxx

正在生成中,你可以:
- 继续生成视频
- 查看生成历史
- 等待完成
```

### 阶段 2B: 生成视频

**用户回复**:
```

```

**系统响应**:
1. 调用 `list_video_models` 查询可用模型
2. 展示模型列表
3. 用户选择后调用 `txt2video`
4. 提交任务

## 潜在问题

### 问题 1: LLM 不主动询问用户

**现象**: 生成提示词后直接结束,没有继续流程

**原因**: 系统提示词指导不够明确

**解决**: 已在提示词中明确要求"主动询问用户"

### 问题 2: 假装已经生成

**现象**: 返回"已为你生成图片"但实际没调用工具

**原因**: LLM 幻觉

**解决**: 系统提示词明确"未从工具结果中确认的都不能当作真实数据"

### 问题 3: 跳过模型查询

**现象**: 直接调用 txt2img 但没查询模型

**原因**: LLM 不知道流程

**解决**: 
1. 工具描述中明确"调用前必须查询模型"
2. execute() 方法有校验,会报错提示

## 补充说明

### 为什么需要两步?

```
用户: "生成图片"
  ↓
系统: 查询模型列表 → 展示给用户
  ↓
用户: 选择模型
  ↓  
系统: 提交生成任务
```

**原因**:
1. 不同用户有不同可用模型(权限不同)
2. 用户可能有偏好(Flux vs SD)
3. 系统不能擅自选择模型

### 能否一步到位?

可以,如果用户明确指定:

```
用户: "用 Flux Pro 生成首帧图"
  ↓
系统: 查询模型 → 找到 Flux Pro → 直接提交
```

关键是 LLM 要先调用 `list_image_models`,从结果中找到匹配的模型 ID。
