## 如何使用

### 1. 通过聊天界面使用

直接向对话 API 发送消息,包含以下关键词即可自动触发 Seedance 工具:

**触发关键词**:
- `seedance`, `即梦`, `视频提示词`
- `短剧`, `视频生成`, `AI视频`
- `运镜`, `镜头`, `分镜`, `剪辑`
- `30秒视频`, `长视频`, `图生视频`

### 2. 使用示例

#### 示例 1: 基础视频(30秒)

**用户输入**:
```
帮我生成一个 30 秒的赛博朋克城市夜景视频,主角是穿着发光外套的女黑客
```

**系统会**:
1. 自动发现 `generate_seedance_prompt` 工具
2. 判断版本: 2.5 (因为30秒)
3. 判断路径: A (概念驱动)
4. 生成符合即梦平台规范的完整提示词,包括:
   - 时间戳分镜 (0-6秒, 6-12秒, ...)
   - 全片一致性锁定
   - 运镜描述
   - 美学约束
   - 首帧图建议
   - 注意事项

#### 示例 2: 图生视频

**用户输入**:
```
我有一张产品图,想做成旋转展示的广告视频,9:16 竖屏
```

**系统会**:
1. 判断路径: C (图生视频)
2. 生成简洁提示词 (300-500字符)
3. 包含 @图片1 引用
4. 补充时长、运镜、节奏信息

#### 示例 3: 长视频 60 秒

**用户输入**:
```
制作一个 60 秒的完整短剧,有起承转合
```

**系统会**:
1. 判断版本: 2.5
2. 判断路径: B (长视频流水线)
3. 生成:
   - 角色卡建议
   - 分镜脚本
   - 逐镜头提示词
   - 剪辑节奏方案

#### 示例 4: 指定 2.0 版本

**用户输入**:
```
用 Seedance 2.0 生成一个 15 秒的产品开箱视频
```

**系统会**:
1. 判断版本: 2.0 (用户明确指定)
2. 时长上限: 15秒
3. 参考素材: 最多12个

## 核心规则(已自动应用)

### 版本差异

| 特性 | 2.0 | 2.5 |
|-----|-----|-----|
| 单次时长 | 15秒 | 30秒(可延长至90秒/180秒) |
| 参考素材 | 12个 | 50个 |
| @引用 | @图片1~9 | @图片1~30 |
| 真人脸 | 一律拦截 | 认证后可用 |

### 路径自动选择

| 路径 | 适用场景 | 自动触发 |
|-----|---------|---------|
| A | 概念驱动 | ≤30秒单条视频 |
| B | 长视频流水线 | >30秒需分镜 |
| C | 图生视频 | 提到"图片"或"图生视频" |
| D | 分镜板驱动 | 提到"分镜板"或"多宫格" |

### 审查规则

- ✅ 全中文提示词
- ✅ @引用格式规范
- ✅ 避免歌名/片名作为台词
- ✅ 真人脸合规检查
- ✅ 时长和素材数量限制

## 常见问题

### Q: 如何指定版本?

A: 在消息中明确提到 "2.0" 或 "2.5",例如:
```
用 Seedance 2.5 生成...
帮我写个 2.0 版本的提示词...
```

如不指定,默认使用 2.5(最新版)。

### Q: 如何提供参考图片?

A: 目前工具返回包含 `@图片1` 的提示词模板。实际使用时:
1. 先在即梦平台上传图片
2. 复制提示词
3. 平台会自动关联图片编号

### Q: 工具生成的提示词可以直接用吗?

A: 可以,但建议:
1. 根据实际需求微调细节
2. 检查台词是否涉及版权
3. 确认素材是否准备齐全
4. 在即梦平台预览效果
